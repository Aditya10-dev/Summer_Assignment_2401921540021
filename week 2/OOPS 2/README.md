# Playable Interface Assignment (Java OOP)

## Objective

Demonstrate the use of Interfaces, Packages, and Polymorphism in Java.

## Problem Statement

1. Create an interface `Playable` with a method:

```java
void play();
```

2. Create a class `Veena` in package `music.string` that implements `Playable`.

3. Create a class `Saxophone` in package `music.wind` that implements `Playable`.

4. Create a class `Test` in package `live` and:

   * Create an instance of `Veena` and call `play()`.
   * Create an instance of `Saxophone` and call `play()`.
   * Store both objects in a reference variable of type `Playable` and call `play()`.

## Concepts Used

* Interface
* Package
* Method Overriding
* Polymorphism
* Object-Oriented Programming (OOP)

## Expected Output

```text
Playing Veena
Playing Saxophone
Playing Veena
Playing Saxophone
```
